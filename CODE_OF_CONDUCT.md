# Code of Conduct

## Our Goal

Docker Mastery is intended to be a welcoming technical learning project.

We expect contributors to:

- Be respectful.
- Be constructive.
- Help others learn.
- Accept reasonable technical disagreement.
- Avoid personal attacks.
- Keep discussions focused on the project.

## Unacceptable Behavior

Examples include:

- Harassment.
- Personal attacks.
- Discrimination.
- Deliberate intimidation.
- Publishing private information.
- Disruptive or abusive behavior.

## Enforcement

Project maintainers may remove comments, close discussions, or reject contributions that violate this Code of Conduct.

Thank you for helping keep the project useful and welcoming.
