# D02 — Docker Architecture Commands

## Docker Version

```bash
docker version
```

Displays Docker client and daemon version information.

## Docker Information

```bash
docker info
```

Displays detailed information about the Docker environment.

## Docker Contexts

```bash
docker context ls
```

Lists Docker contexts and identifies the active context.

## List Images

```bash
docker images
```

Equivalent:

```bash
docker image ls
```

## List Running Containers

```bash
docker ps
```

## List Docker Networks

```bash
docker network ls
```

## List Docker Volumes

```bash
docker volume ls
```

## Command Reference

| Command | Purpose |
|---|---|
| `docker version` | Show Docker client and daemon versions |
| `docker info` | Show Docker environment information |
| `docker context ls` | List Docker contexts |
| `docker images` | List local images |
| `docker ps` | List running containers |
| `docker network ls` | List Docker networks |
| `docker volume ls` | List Docker volumes |
